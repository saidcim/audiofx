# songs/

Drop the audio files you want to process into this folder.

Supported extensions: `.mp3` `.wav` `.flac` `.m4a` `.aac` `.ogg` `.opus` `.wma`

Open the interface by double clicking `audiofx.bat` in the project root, or by
running:

```bash
python -m audiofx gui
```

Press **Refresh** in the app after adding new files. Results are written to
`../output`.

Audio files in this folder are ignored by git - keep it that way, and only put
material here that you have the rights to.
